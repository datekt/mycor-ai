# 🧠 MYCOR (Майкор) — v4.3

> **My Core. Zero Dependencies. Pure Go. Dynamic Context. Persistent Memory. Thinking.**

**MYCOR** — это абсолютно «пустая» локальная языковая модель на чистом **Go 1.27.1**, созданная с нуля без использования сторонних фреймворков (PyTorch, TensorFlow), Python или тяжёлых C-библиотек (CGO).

В эпоху терабайтных корпоративных чёрных ящиков **MYCOR** возвращает контроль в руки разработчика. Это цифровая песочница и холст, характер которого вы формируете полностью сами.

---

## 🎯 Философия проекта

При первом запуске MYCOR — это «чистая доска» (Tabula Rasa). На любой ваш запрос модель будет выдавать хаотичный бред. У неё нет заложенных знаний, цензуры или предвзятости.

**Она учится только у вас.** Общаясь с ней в консоли и корректируя её ответы, вы буквально с нуля формируете её «мозг» (динамическую матрицу весов N-грамм). Вырастите свою собственную, пускай и простую, но по-настоящему *личную* нейросеть прямо на своём локальном железе.

---

## 🆕 Что нового в v4.3

- 💭 **Режим размышления (Thinking Mode):** Перед тем как ответить, нейросеть генерирует внутреннюю цепочку из нескольких токенов-мыслей. Этот «черновик» становится контекстом для финального ответа. Включается автоматически, когда в словаре накопится **минимум 10 слов**.
- 👁️ **Прозрачность мыслей:** Строка `💭 Мысли MYCOR: ...` показывает, что сеть «подумала» перед ответом. Полезно для отладки характера и понимания внутренней логики.
- 🧮 **Улучшена инициализация `unk`-колонки:** При загрузке старого `history.json` без `<unk>`-токена соответствующие веса инициализируются нулём, а не случайным шумом — модель не «дрожит» сразу после загрузки.
- 🛡️ **Исправлен баг `RegisterWord`:** Матрица весов и словарь больше не могут рассинхронизироваться при массовой регистрации слов.
- 🧹 **Исправлен `/reset`:** Полностью сбрасывает в том числе состояние мыслей и недавние контексты.
- 🔧 **Мелкие исправления:** Атомарное сохранение не оставляет `.tmp`-файлов при ошибке, отфильтрован `<unk>` из генерируемого ответа, улучшена статистика `/stats` (показывает статус режима размышления).
- ⬆️ **Go 1.27.1** — обновлена версия в `go.mod`.

## ✨ Ключевые особенности v4.3

- 📦 **Zero Dependencies:** Использует исключительно стандартную библиотеку Go.
- 🚀 **N-Gram Context Window:** Скользящее контекстное окно из двух слов для связной речи.
- 🧠 **Динамический векторный словарь:** Новые слова расширяют весовую матрицу «на лету».
- 💭 **Thinking Mode:** Латентная цепочка размышлений перед ответом (активируется при ≥10 словах).
- 💾 **Персистентная память:** Обученный мозг сохраняется в `history.json` и восстанавливается при перезапуске. История диалога сессии при этом сбрасывается — она живёт только в оперативной памяти.
- 📊 **Инженерная консоль управления:** Команды для мониторинга Loss, температуры, скорости обучения и инерции.
- 📖 **Пакетный импорт:** Мгновенное автообучение на текстовом файле.
- 🌀 **Momentum Optimizer:** Обновление весов с инерцией (EMA-градиент).
- 🧮 **L2 Weight Decay:** Лёгкая регуляризация против «раздувания» весов.
- 🛡️ **Атомарное сохранение:** Запись мозга через временный файл с последующим `rename`.
- 🔒 **Строгая валидация:** Проверка дубликатов слов, корректной длины весов и целостности JSON при загрузке.
- 🧪 **Покрытие тестами:** Полный набор модульных тестов для движка, импортёра и режима размышления.

## 🚀 Быстрый старт

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone (ссылка)
   cd mycor
   ```

2. Запустите модель (точка в конце обязательна для сборки модулей):
   ```bash
   go run .
   ```

3. Начните общение! Введите фразу, посмотрите на ответ, а затем введите правильный вариант ответа для обучения. Нажмите `Enter` без ввода текста, если хотите пропустить шаг обучения.

4. После того как в словаре накопится 10+ слов, перед каждым ответом появится строка `💭 Мысли MYCOR:` — это внутренний монолог сети перед финальной репликой.

## 🕹️ Команды панели управления

- `/help` — Показать полный список команд.
- `/stats` — Текущее количество синапсов, статус режима размышления и последние активные контексты.
- `/history` — Просмотр истории диалога текущей сессии.
- `/undo` — Отменить последний урок.
- `/reset` — Полностью стереть файл `history.json` и начать с чистого листа.
- `/temp [0.1 - 1.5]` — Креативность (температура Softmax).
- `/lr [0.01 - 1.0]` — Скорость обучения.
- `/momentum [0.0 - 0.99]` — Инерция градиента (по умолчанию 0.9).
- `/import [путь_к_файлу]` — Пакетное обучение из текстового файла.
- `/self` — Автономный диалог ИИ с зеркалом (с отображением мыслей).
- `exit` — Безопасный выход с сохранением весов.

## 🧠 Память: что сохраняется, а что сбрасывается

**Сохраняется в `history.json` и переживает перезапуск:**
- Словарь (`vocabulary`).
- Весовая матрица (`weights`).
- Состояние оптимизатора (`velocity`, momentum).

**Сбрасывается при каждом запуске:**
- История диалога текущей сессии.
- Список недавних активных контекстов.
- Последние «мысли» сети (`lastThoughts`).
- Резервная копия для `/undo`.

Такое разделение позволяет накапливать знания между сессиями, но не тащить за собой случайный мусор из прошлых разговоров.

## 💭 Как работает режим размышления

1. **Порог активации:** `MinVocabForThinking = 10`. Пока в словаре меньше 10 уникальных слов, модель отвечает мгновенно, как в v4.2.
2. **Внутренняя генерация:** При активации движок делает `thinkingSteps = 4` шагов семплирования из той же весовой матрицы, но не показывает их пользователю напрямую во время генерации.
3. **Контекст ответа:** Полученная «мысль» становится префиксом к промпту, и финальный ответ генерируется уже из расширенного контекста. То есть ответ — это продолжение размышления.
4. **Прозрачность:** Строка `💭 Мысли MYCOR:` выводится после ответа, чтобы вы могли наблюдать за внутренней логикой. В `/stats` отображается текущий статус режима.

Такой подход даёт эффект «двухступенчатого» вывода: сначала модель проигрывает несколько альтернативных продолжений, а затем строит на них ответ.

## 🛠️ Как это устроено изнутри

Математика MYCOR занимает чуть больше 300 строк кода в папке `engine/`. Архитектура построена на марковских переходах цепей контекста `[слово1 + слово2] -> слово3`.

Обучение использует:
- **Softmax с численной стабилизацией** (сдвиг на максимум).
- **Кросс-энтропию** как функцию потерь.
- **SGD с инерцией (EMA-градиент):** `v = m*v + (1-m)*grad; w = w*decay + lr*v`.
- **Weight Decay:** параметр `WeightDecay` в конфиге.

Генерация использует:
- **Температуру Softmax** для управления креативностью.
- **Repetition Penalty** для борьбы с зацикливанием.
- **Thinking Mode** для внутреннего монолога перед ответом.

Поскольку локальный файл `history.json` внесён в `.gitignore`, репозиторий публикуется **абсолютно чистым**. Каждый пользователь создаёт свой уникальный цифровой разум.

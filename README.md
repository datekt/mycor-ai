# 🧠 MYCOR (Майкор) — v4.1

> **My Core. Zero Dependencies. Pure Go. Dynamic Context.**

**MYCOR** — это абсолютно «пустая» локальная языковая модель на чистом **Go 1.27**, созданная с нуля без использования сторонних фреймворков (PyTorch, TensorFlow), Python или тяжелых C-библиотек (CGO). 

В эпоху терабайтных корпоративных черных ящиков, **MYCOR** возвращает контроль в руки разработчика. Это цифровая песочница и холст, характер которого вы формируете полностью сами.

---

## 🎯 Философия проекта

При первом запуске MYCOR — это «чистая доска» (Tabula Rasa). На любой ваш запрос модель будет выдавать хаотичный бред. У нее нет заложенных знаний, цензуры или предвзятости.

**Она учится только у вас.** Общаясь с ней в консоли и корректируя её ответы, вы буквально с нуля формируете её «мозг» (динамическую матрицу весов N-грамм). Вырастите свою собственную, пускай и простую, но по-настоящему *личную* нейросеть прямо на своем локальном железе.

## ✨ Ключевые особенности v4.1

- 📦 **Zero Dependencies:** Использует исключительно стандартную библиотеку Go. Никаких виртуальных окружений Python, CUDA или внешних API.
- 🚀 **N-Gram Context Window:** Скользящее контекстное окно из двух слов. Модель не просто ассоциирует слова попарно, а помнит фразу на шаг назад, что делает структуру речи связной.
- 🧠 **Динамический векторный словарь:** Модель не ограничена по буквам. Каждое новое слово расширяет векторную матрицу весов «на лету» прямо во время диалога.
- 📊 **Инженерная консоль управления:** Встроенные команды для мониторинга Loss (ошибки сети), изменения параметров креативности (`Temperature`) и скорости обучения (`Learning Rate`).
- 📖 **Пакетный импорт:** Возможность моментально «скормить» модели текстовый файл книги или архив переписки из мессенджера для автообучения.

## 🚀 Быстрый старт

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone (ссылка)
   cd mycor
   ```

2. Запустите модель (точка в конце обязательна для сборки модулей):
   ```bash
   go run .
   ```

3. Начните общение! Введите фразу, посмотрите на ответ, а затем введите правильный вариант ответа для обучения. Нажмите `Enter` без ввода текста, если хотите пропустить шаг обучения.

## 🕹️ Команды панели управления

Используйте системные команды прямо в окне чата для администрирования нейросети:

- `/help` — Показать полный список доступных интерактивных команд.
- `/stats` — Посмотреть текущее количество синапсов (параметров весов) и топ последних активных речевых зон в памяти.
- `/undo` — Отменить последний неудачный урок (если вы опечатались или ввели неверный ответ).
- `/reset` — Полностью стереть файл текущей памяти (`history.json`) и начать обучение с чистого листа.
- `/temp [0.1 - 1.5]` — Регулировка креативности (температуры Softmax). Низкие значения (например, 0.2) делают речь строгой, высокие (1.2+) — непредсказуемой и хаотичной.
- `/lr [0.01 - 1.0]` — Изменение скорости обучения (Learning Rate) для тонкой настройки весов.
- `/import [путь_к_файлу]` — Пакетное обучение. Передайте модели текстовый файл (например, `/import book.txt`), и ИИ за секунды прогонит через себя весь текст, выстраивая новые связи.
- `/self` — Режим автономного диалога. Запускает цикл, в котором ИИ общается сам со своим отражением на основе накопленных весов.
- `exit` — Безопасный выход с сохранением весов матрицы.

## 🛠️ Как это устроено изнутри

Вся математика MYCOR занимает чуть больше 200 строк кода в папке `engine/`. Архитектура построена на марковских переходах цепей контекста `[слово1 + слово2] -> слово3`. При отправке правильного ответа алгоритм, вдохновленный SGD (стохастическим градиентным спуском) для кросс-энтропии, вычисляет математическую ошибку (`Loss`) и корректирует распределение вероятностей `Softmax` в файле памяти. 

Поскольку локальный файл `history.json` внесен в `.gitignore`, репозиторий публикуется **абсолютно чистым**. Каждый пользователь создает свой уникальный цифровой разум.

### 💡 Лайфхак: Обучение через Большой ИИ (DeepSeek / Claude)
Вы можете сгенерировать характер за секунды. Запустите модель один раз, чтобы сформировался базовый файл `history.json`. Передайте этот файл в DeepSeek и попросите его:
> *«Перед тобой файл весов `history.json` от контекстной модели MYCOR на Go. Измени числа внутри этой матрицы так, чтобы модель научилась отвечать в стиле [выбрать персонажа/стиль]. Верни мне измененный JSON целиком»*.

Замените полученным текстом свой файл и запустите проект!

# 🧠 MYCOR (Майкор) — v4.2

> **My Core. Zero Dependencies. Pure Go. Dynamic Context. Persistent Memory.**

**MYCOR** — это абсолютно «пустая» локальная языковая модель на чистом **Go 1.27**, созданная с нуля без использования сторонних фреймворков (PyTorch, TensorFlow), Python или тяжёлых C-библиотек (CGO).

В эпоху терабайтных корпоративных чёрных ящиков **MYCOR** возвращает контроль в руки разработчика. Это цифровая песочница и холст, характер которого вы формируете полностью сами.

---

## 🎯 Философия проекта

При первом запуске MYCOR — это «чистая доска» (Tabula Rasa). На любой ваш запрос модель будет выдавать хаотичный бред. У неё нет заложенных знаний, цензуры или предвзятости.

**Она учится только у вас.** Общаясь с ней в консоли и корректируя её ответы, вы буквально с нуля формируете её «мозг» (динамическую матрицу весов N-грамм). Вырастите свою собственную, пускай и простую, но по-настоящему *личную* нейросеть прямо на своём локальном железе.

## ✨ Ключевые особенности v4.2

- 📦 **Zero Dependencies:** Использует исключительно стандартную библиотеку Go.
- 🚀 **N-Gram Context Window:** Скользящее контекстное окно из двух слов для связной речи.
- 🧠 **Динамический векторный словарь:** Новые слова расширяют весовую матрицу «на лету».
- 💾 **Персистентная память:** Обученный мозг сохраняется в `history.json` и восстанавливается при перезапуске. История диалога сессии при этом сбрасывается — она живёт только в оперативной памяти.
- 📊 **Инженерная консоль управления:** Команды для мониторинга Loss, температуры, скорости обучения и инерции.
- 📖 **Пакетный импорт:** Мгновенное автообучение на текстовом файле.
- 🌀 **Momentum Optimizer:** Обновление весов с инерцией (EMA-градиент) для более стабильного и быстрого обучения.
- 🧮 **L2 Weight Decay:** Лёгкая регуляризация против «раздувания» весов.
- 🛡️ **Атомарное сохранение:** Запись мозга через временный файл с последующим `rename` — модель не повредится при сбое.
- 🔒 **Строгая валидация:** Проверка дубликатов слов, корректной длины весов и целостности JSON при загрузке.
- 🧪 **Покрытие тестами:** Полный набор модульных тестов для движка и импортёра.

## 🚀 Быстрый старт

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone (ссылка)
   cd mycor
   ```

2. Запустите модель (точка в конце обязательна для сборки модулей):
   ```bash
   go run .
   ```

3. Начните общение! Введите фразу, посмотрите на ответ, а затем введите правильный вариант ответа для обучения. Нажмите `Enter` без ввода текста, если хотите пропустить шаг обучения.

## 🕹️ Команды панели управления

- `/help` — Показать полный список команд.
- `/stats` — Текущее количество синапсов и последние активные контексты.
- `/history` — Просмотр истории диалога текущей сессии (сбрасывается при перезапуске).
- `/undo` — Отменить последний урок.
- `/reset` — Полностью стереть файл `history.json` и начать с чистого листа.
- `/temp [0.1 - 1.5]` — Креативность (температура Softmax).
- `/lr [0.01 - 1.0]` — Скорость обучения.
- `/momentum [0.0 - 0.99]` — Инерция градиента (по умолчанию 0.9).
- `/import [путь_к_файлу]` — Пакетное обучение из текстового файла.
- `/self` — Автономный диалог ИИ с зеркалом.
- `exit` — Безопасный выход с сохранением весов.

## 🧠 Память: что сохраняется, а что сбрасывается

**Сохраняется в `history.json` и переживает перезапуск:**
- Словарь (`vocabulary`).
- Весовая матрица (`weights`).
- Состояние оптимизатора (`velocity`, momentum).

**Сбрасывается при каждом запуске:**
- История диалога текущей сессии.
- Список недавних активных контекстов.
- Резервная копия для `/undo`.

Такое разделение позволяет накапливать знания между сессиями, но не тащить за собой случайный мусор из прошлых разговоров.

## 🛠️ Как это устроено изнутри

Математика MYCOR занимает чуть больше 250 строк кода в папке `engine/`. Архитектура построена на марковских переходах цепей контекста `[слово1 + слово2] -> слово3`.

Обучение использует:
- **Softmax с численной стабилизацией** (сдвиг на максимум).
- **Кросс-энтропию** как функцию потерь.
- **SGD с инерцией (EMA-градиент):** `v = m*v + (1-m)*grad; w = w*decay + lr*v`.
- **Weight Decay:** параметр `WeightDecay` в конфиге.

Поскольку локальный файл `history.json` внесён в `.gitignore`, репозиторий публикуется **абсолютно чистым**. Каждый пользователь создаёт свой уникальный цифровой разум.

### 💡 Лайфхак: Обучение через Большой ИИ (DeepSeek / Claude)

Вы можете сгенерировать характер за секунды. Запустите модель один раз, чтобы сформировался базовый файл `history.json`. Передайте этот файл в DeepSeek и попросите:

> *«Перед тобой файл весов `history.json` от контекстной модели MYCOR на Go. Измени числа внутри этой матрицы так, чтобы модель научилась отвечать в стиле [выбрать персонажа/стиль]. Верни мне изменённый JSON целиком».*

Замените полученным текстом свой файл и запустите проект.
